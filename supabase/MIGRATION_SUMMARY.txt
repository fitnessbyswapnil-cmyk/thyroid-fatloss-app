TASK 3: HANDLE_NEW_USER TRIGGER VERIFICATION & CREATION
================================================================================

✅ VERIFIED & CREATED: Trigger now exists and auto-creates client profiles.

Function Details:
  Name: public.handle_new_user()
  Language: plpgsql
  Security: DEFINER (runs with elevated privileges)
  Search Path: public (isolated scope)

Trigger Details:
  Name: on_auth_user_created
  Event: AFTER INSERT ON auth.users
  Action: Calls handle_new_user() for each new user
  Behavior: 
    - Creates row in clients table
    - Sets full_name from metadata or email
    - Sets email from auth.users.email
    - Sets role from metadata (defaults to 'client')
    - ON CONFLICT (id) DO NOTHING (prevents duplicates)

Security:
  ✅ SECURITY DEFINER allows trigger to bypass client RLS
  ✅ Automatically creates profile without app intervention
